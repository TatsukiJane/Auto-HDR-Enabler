# AGENTS.md

Инструкции для ИИ-агентов. Файл кросс-инструментальный (AGENTS.md читают многие агенты).
Подробный источник правды — [CLAUDE.md](CLAUDE.md): архитектура, решения и подводные камни.

## Что это

Auto HDR — приложение в трее для Windows 11: включает HDR на выбранных мониторах при запуске игры
и возвращает SDR после её закрытия. Описание для пользователя — в [README.md](README.md).

## Стек и сборка

- C# / .NET 10, WPF (`net10.0-windows`), WinForms только для значка в трее. Один проект: `AutoHdr/AutoHdr.csproj`.
- Единственная зависимость — NuGet-пакет `System.Management` (события запуска процессов через WMI).
- Остальное — P/Invoke в Windows API (`AutoHdr/Core/Native.cs`).
- Решения (`.sln`) нет, тестового проекта нет.

## Как запускать и проверять

| Что | Команда |
|---|---|
| Проверить, что код компилируется | `dotnet build AutoHdr/AutoHdr.csproj -c Debug` |
| Собрать релизный exe | `powershell -ExecutionPolicy Bypass -File build.ps1` → `dist\AutoHdr.exe` |
| Нарисовать вкладки окна в PNG | `AutoHdr.exe --data <папка> --snapshot <папка>` |
| Прочитать состояние HDR | `AutoHdr.exe --data <папка> --hdr status` |

- Автотестов нет. Минимальная проверка любой правки — `dotnet build` без ошибок и предупреждений.
- Для запусков из агента всегда передавай `--data <папка вне AppData>` первым аргументом,
  чтобы не трогать настоящие настройки пользователя и не попасть в виртуализацию AppData (см. CLAUDE.md).
- `build.ps1` закрывает работающую копию приложения (`--exit`), потому что она держит exe открытым.
- `--hdr on|off|toggle` реально переключает режим экрана пользователя: делай это только с его ведома.

Что агент проверить не может и не должен выдавать за проверенное:
- поведение на реальных играх (запуск, «Ждать HDR», лаунчеры, античиты);
- как выглядит картинка в HDR и SDR;
- работу автозапуска после входа в Windows.

## Ключевые ограничения

- Не выключать HDR, который пользователь включил сам: возвращается только то, что включило приложение
  (`AppSettings.PendingRevert`).
- Авто-HDR для игры по умолчанию выключен, кроме подтверждённых Steam или PCGamingWiki.
  Ручной выбор пользователя всегда главнее (`GameRecord.UserOverride`).
- Мониторы — по явному согласию: телевизоры, виртуальные дисплеи и все мониторы, подключённые позже, добавляются выключенными.
- Манифест — `asInvoker`. Права администратора приложение получает только через задачу планировщика.
- Внедрение в процессы игр (хук DXGI и т. п.) пользователь отклонил. Не предлагать без явной просьбы.

## Конвенции

- Интерфейс, журнал, комментарии и документация — на русском.
- C#: 4 пробела, file-scoped namespace, `Nullable` включён, коллекции через `[]`.
- Данные приложения — JSON в `%LOCALAPPDATA%\AutoHdr`, запись через `JsonStore` (атомарно, через `.tmp`).
- Скрипты `.ps1` с кириллицей сохранять в UTF-8 с BOM: Windows PowerShell 5.1 иначе читает их неверно.
- Переносы строк — LF (`.gitattributes`), стиль — `.editorconfig`.
